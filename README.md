# GoodbyeDPI Ayar

Discord ve Roblox açılsın diye hazırlanmış GoodbyeDPI başlatma dosyaları ve adres listesi. `goodbyedpi.exe` bu depoda yok; GoodbyeDPI-Turkey klasöründe durur.

## Ne var

Pencereyle başlatma, Windows servisi kurup kaldırma, DNS düzeltme ve `liste.txt`. GoodbyeDPI yalnızca bu listedeki adreslerin bağlantı başlangıcına dokunur. Steam, Epic Games ve tarayıcı indirmeleri listede değildir.

## Çalıştırma

Bu klasör GoodbyeDPI-Turkey içinde durmalı. Yönetici olarak önce `6-dns-duzelt.cmd`, sonra ya `1-pencere-ile-baslat.cmd` ya da `2-servis-kur.cmd` çalıştır. İkisini birden açma.

Adım adım anlatım `README.txt` içindedir.

## Yığın

Windows komut dosyaları ve PowerShell. Altyapı GoodbyeDPI.
